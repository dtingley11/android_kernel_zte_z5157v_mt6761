# Z5157V ER68577 BOE panel

The `zte_mango_zhongguangdian_er68577_720p_5p45_boe` MediaTek LCM driver
restores the sixth panel selected by the stock Z5157V configuration.
Its bootloader-visible name is
`zte_mango_zhongguangdian_er68577_720p_5p45_boe_drv`.
The other five panel registrations and their ordering are retained.

## Provenance

The common MediaTek LCM helpers are derived from the existing mango ST7703
HSD driver in vendor revision
`271f50e97d5ab64a7c7caa86e53e7bb720047ef3`. Panel-specific data and callback
behavior were recovered from the supplied stock ARM kernel, whose embedded
driver identifies itself as `20210805_v0`.

Stock zImage, including its appended DTB, SHA-256:
`9f29e359222a273c6d10daa85a929cdc3b85bda414c95a435f1bcb7f8b25594a`.
The stock image is not distributed in this repository.

The related [ZTE ER68577 BOE panel definition](https://github.com/webusis/zte-blade-a31/blob/b31c2f3af4b06d4984c1ffb50cbd5a773452b2bc/arch/arm/boot/dts/harry/zte_lcd_zhongguangdian_er68577_boe_5p45_720p.dtsi),
revision `b31c2f3af4b06d4984c1ffb50cbd5a773452b2bc`, independently matches all
30 initialization command payloads. Its Spreadtrum framework, timing,
reset, voltage and delay settings were not substituted for the stock
MediaTek settings.

## Recovered settings

| Setting | Stock value |
| --- | --- |
| Resolution | 720 × 1440 |
| Physical dimensions | 61884 × 123768 µm |
| DSI | Three lanes, RGB888, sync-pulse video mode |
| Vertical sync / back porch / front porch | 4 / 30 / 20 |
| Horizontal sync / back porch / front porch | 40 / 72 / 80 |
| PLL clock | 343 MHz |
| TPS65132B voltage setting | `0x10` |
| Initial reset sequence | Low, 1 ms; high, 80 ms |
| Resume-power reset sequence | Low, 10 ms; high, 10 ms |
| Sleep-out / display-on delays | 120 / 20 ms |
| Suspend | Display off, 50 ms; sleep in, 240 ms; stock E9/C6 commands |
| Suspend-power | Low reset and bias off; retains separate shutdown delays |
| Backlight | Stock 8-bit DCS `0x51` handling |

The stock callback table is at virtual address `0xc15bd65c` in the supplied
kernel; `get_params` is at `0xc07ba454`, initialization at `0xc07ba798`,
and its 32-entry initialization table at `0xc15bcb1c`. The reconstructed
source uses this tree's LCM structures and the existing TPS65132B interface.

## Comparison

`tools/testing/z5157v-panel` compiles the actual driver source and invokes
the isolated stock ARM callbacks under QEMU. Kernel helper calls and every
hardware-facing operation are redirected to userspace test callbacks.
The script accepts only the stock image hash above.

With Android NDK r27d and QEMU ARM, all 1204 `LCM_PARAMS` bytes matched.
273 cases matched stock traces and return values: initialization, resume,
normal/shutdown power-off, suspend commands, both mode-switch paths, region
updates, ESD and ATA success/failure, and brightness levels 0 through 256.
Logging text is excluded from the comparison. This is a callback comparison,
not hardware emulation or a device test.

The stock device configuration includes all six panel drivers. Physical panel identity, bootloader panel
selection, display output, touch, brightness, suspend/resume and ESD
recovery still require testing on the Z5157V.
